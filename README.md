## 1. 現状分析

### 宅建試験ドットコム（https://takken-siken.com/kakomon.php）

**強み**
- 26年分1,400問収録、ユーザー登録者数99,100人
- PWA対応、ダークモード、学習履歴、分析レポート、模擬試験、PDF出力
- 2018年から8年間継続運用、月単位で機能追加
- メンバーシップによる収益化の仕組みが既にある

**弱み**
- デザインが2000年代後半〜2010年代初頭で止まっている
- ブラウザ標準のチェックボックス/ラジオボタン
- フォント統一感なく、余白・行間不十分
- jQuery 3.4.1依存
- モバイル表示がPCの縮小版

## 3. 収益モデルの結論

### アフィリエイトは辞めるべき

- 教材（本）のアマゾン報酬は3〜5%、1件あたり30〜100円
- 「アフィリサイトです」という印象が課金転換の足を引っ張る
- 差別化できないコモディティ戦争になる

### サブスク（月額課金）一択

- 月額580円（税込、中間値）
- 無料ユーザーには広告表示（AdSense）
- 有料ユーザーは広告非表示＋全機能＋学習分析＋PDF出力

### 3サイトの収益試算

| サイト | 初年度 | 2年目以降（安定時） |
|---|---|---|
| 宅建 | 約1,008万円 | 約1,680万円 |
| 簿記3級 | 約336万円 | 約1,008万円 |
| 簿記2級 | 約240万円 | 約720万円 |
| **合計** | **約1,584万円** | **約3,408万円** |

### 一人で運営可能

- サーバー代 月3〜5万円（3サイト合計）のみ
- 宅建は年1回の法改正対応のみ
- 簿記は法改正がほとんどない
- サブスク決済はStripe任せで自動化
- 月数時間のメンテナンスで回る

## 4. なぜ簿記3級・2級なのか

### 宅建より簿記の方が市場が大きい

| 項目 | 宅建 | 簿記3級 | 簿記2級 |
|---|---|---|---|
| 年間受験者 | 20〜25万人 | 30〜40万人 | 20〜25万人 |
| 試験回数 | 年1回 | 年3回 | 年3回 |
| 学習期間 | 3〜6ヶ月 | 2〜4ヶ月 | 3〜6ヶ月 |
| 無料過去問サイトの決定版 | ✅ 宅建試験ドットコムがいる | ❌ いない（空白市場） | ❌ いない |

### 決定版がいない空白市場

日商簿記3級・2級には、宅建試験ドットコムクラスの「無料で高品質な過去問演習サイト」が存在しない。競合は以下のような状況：

- 簿記過去問道場系：存在するがUIが古く問題数が少ない
- パブロフ流（アプリ）：有料アプリでスマホのみ
- ふくしま簿記（YouTube）：解説は神だが問題演習機能なし
- その他無料サイト：広告まみれ、使いにくい

### 宅建のコード資産がそのまま流用できる

必要なのは：
1. 問題データベースの差し替え（簿記の過去問を収録）
2. デザインカラーの変更
3. 試験回・分野構成の変更

→ **1サイトあたり1〜2週間で立ち上げ可能**

### 簿記3級→2級のアップセルが効く

- 3級合格者が「次は2級」と目指すのは自然な流れ
- 3級サイト内に2級のリンクを貼るだけでクロスセル
- ユーザー獲得コストがほぼゼロ

## 9. 決定打：「589円（税込）でガチ解説サブスク」

### このアイデアが刺さる理由

**「無料で問題が解けるサイトはある。でも、解説が充実しているサイトはない。」**

これがこの市場の決定打になる。

### 現状の解説の質（競合比較）

| サイト | 問題数 | 解説の質 | 課金 |
|---|---|---|---|
| 宅建試験ドットコム（現状） | 1,400問 | 「正解は〇」「〜により△」程度の簡素な解説 | メンバーシップ（機能制限） |
| パブロフ流（簿記アプリ） | 限定 | 図解入りで充実 | 有料アプリ（買い切り） |
| ふくしま簿記（YouTube） | — | 神解説だが問題演習は別 | 無料 |
| その他無料サイト | 少ない | ほとんど解説なし or コピペ | なし |

### 「589円でガチ解説」の勝ちパターン

| 項目 | 現状の宅建サイト | リニューアル後 |
|---|---|---|
| 無料でできること | 問題を解く、正誤確認 | 問題を解く、正誤確認、簡単な解説 |
| **有料（589円/月）でできること** | ★マークの問題が解ける | **問題数制限なし + ガチ解説全文 + PDF + 学習分析 + 広告なし** |
| 解説の量 | 1行〜3行 | **段落単位の詳細解説 + 根拠条文 + 判例 + 間違いやすいポイント** |
| 解説の品質 | 「〜により正しい」 | **「なぜ正しいのか」「なぜ間違いなのか」「どういうケースで例外があるのか」まで書く** |

### 589円の価格設定が絶妙な理由

- **500円玉1枚 + 小銭** = 心理的ハードルが低い（月額600円より安く感じる）
- 「たった589円で、予備校のテキスト並みの解説が読める」という価値提案が成立する
- 消費税込589円（本体価格540円） = 決済手数料引いても500円以上残る
- スマホ決済（Apple Pay / Google Pay）ならワンタップで契約できる金額

### 「ガチ解説」の書き方（差別化のポイント）

```
【現状の解説】
誤り。建物の区分所有等に関する法律第3条により、区分所有者の団体は
区分所有者全員で構成される。

【ガチ解説（589円会員向け）】
❌ 誤り。

建物の区分所有等に関する法律（区分所有法）第3条では、
「区分所有者の団体は、区分所有者全員で構成される」と定められています。

つまり、管理組合の構成員は「建物の区分所有者」であり、
「建物の賃借人（入居者）」は含まれません。
賃借人は管理組合の総会に出席することはできますが（第6条）、
議決権はなく、団体の構成員ではありません。

【間違いやすいポイント】
・「賃借人も管理組合のメンバーだ」と誤解する人が多いので注意
・管理組合の役員になることができるのは区分所有者のみ
・賃借人は「使用細則」に従う義務はあるが、組合員ではない

【関連条文】
・区分所有法 第3条（団体の構成）
・区分所有法 第6条（賃借人の権利）
```

**1問あたりの解説を100〜200字から500〜800字に増やす。これが「589円の価値」になる。**

### 収益試算（再計算）

有料転換率を上げる要素：
- 「ガチ解説」が差別化要因になる → 無料ユーザーが「解説だけでも読みたい」と思う
- 589円という低価格 → 試しやすくなる
- → 転換率4% → 6%に上がる可能性が高い

| サイト | 転換率4%（旧） | 転換率6%（589円＋ガチ解説） |
|---|---|---|
| 宅建（MAU 3万人） | 1,200人 → 月69万円 | **1,800人 → 月106万円** |
| 簿記3級（MAU 1万人） | 400人 → 月23万円 | **600人 → 月35万円** |
| 簿記2級（MAU 5,000人） | 200人 → 月11万円 | **300人 → 月17万円** |
| FP3級（MAU 5,000人） | 200人 → 月11万円 | **300人 → 月17万円** |
| **全4サイト合計** | **月114万円 / 年1,368万円** | **月175万円 / 年2,100万円** |

さらに、解説を書き溜めておけば**新しくサイトを増やすときの解説コストがゼロになる**（過去に書いた解説ベースで流用・調整するだけ）。

### 結論

**「589円でガチ解説サブスク」はこのビジネスモデルの決定打。**
- 競合が真似できない理由：ガチ解説を書くのに膨大な工数がかかる（一度書けば終わりだが）
- ユーザーが課金する理由：「解説が神」
- 値段が安いので「月1回のランチ代」の感覚で契約してもらえる

「ガチ解説」は一回書けば半永久的に資産になる。問題が変わらない限り、書き直す必要がない。これが**ストック型ビジネスとして最も強い形。**

## 9. お願いしたいこと

# 宅建魔導書 図解実装計画書

## 基本方針

- **SVGで記述**（CSS変数対応、テキスト選択可能、レスポンシブ）
- 各記事に **1〜2図** を挿入（h2直下など要点の視覚化が必要な箇所）
- カラーは既存CSS変数 `--gold`, `--rune`, `--blood` などと調和させる
- 図は `.article .diagram` クラスでラップし、max-width 100%

## SVG実装の構成

```html
<div class="diagram">
  <svg viewBox="0 0 600 300" class="diagram-svg">
    <!-- SVG contents -->
  </svg>
</div>
```

```css
.article .diagram {
  margin: 24px 0;
  background: #faf6eb;
  border: 1px solid #e6dac6;
  border-radius: 10px;
  padding: 16px;
}
.article .diagram svg {
  width: 100%;
  height: auto;
  display: block;
}
```

- viewBox は 600×300 を基本サイズに、内容に応じて調整
- フォントは `font-family="Outfit, Noto Sans JP, sans-serif"` を指定
- 色は hex 直書き（SVG内部ではCSS変数が使えないため）

## 実装優先順位

1. **Phase 1**: フローチャート・比較表・階層図（需要が高いLv1,4,5,11,16,17,20,24,25から）
2. **Phase 2**: 断面図・関係図（Lv7,8,13,18,21,29）
3. **Phase 3**: カード配置・グラフ（Lv12,22,27,28,31,32）

---

## 1記事あたりの工数目安

- 単純な比較表/フローチャート: 5〜10分
- 複雑な断面図/関係図: 15〜25分
- 全33記事: 約8時間（分割実行推奨）

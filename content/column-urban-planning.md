宅建試験「法令上の制限」の**最重要単元**、それが**都市計画法（としけいかくほう）**です。

都市計画法は、**「どこに」「どんな建物を」「どのくらいの規模で」建てられるか**を定める法律です。
不動産取引の現場では、物件の用途地域や建ぺい率・容積率を確認することが基本中の基本です。

---

### 都市計画法の目的

都市計画法の目的は、**都市の健全な発展と秩序ある整備**を図ることです。

具体的には、以下の3つをコントロールします：
1. **用途**：何に使うか（住宅・商業・工業など）
2. **規模**：どれくらいの大きさか（建ぺい率・容積率）
3. **形態**：どのような形か（高さ・デザインなど）

---

### 都市計画区域

都市計画法が適用される区域は、**都市計画区域**として指定されます。

| 区域の種類 | 内容 |
|:---|:---|
| **都市計画区域** | 都市計画法が適用される区域。市街化区域と市街化調整区域に分けられる |
| **市街化区域** | すでに市街地を形成している区域。または優先的・計画的に市街化を図る区域 |
| **市街化調整区域** | 市街化を抑制すべき区域。原則として開発行為が制限される |
| **非線引き都市計画区域** | 市街化区域と市街化調整区域の区分（線引き）がない都市計画区域 |
| **準都市計画区域** | 都市計画区域外で、相当数の建築物が存在する区域 |

### 用途地域（都市計画法第8条〜第13条）

**用途地域**とは、**土地の利用目的に応じて13種類に分類された地域**です。

| 種類 | 建てられる主な建物 | 用途制限の強さ |
|:---|:---|:---:|
| **第1種低層住居専用地域** | 低層住宅（2階建て程度）、小規模店舗（床面積50㎡以下） | 強い |
| **第2種低層住居専用地域** | 低層住宅＋小規模店舗（150㎡以下） | ↑ |
| **第1種中高層住居専用地域** | 中高層住宅、病院、大学 | ｜ |
| **第2種中高層住居専用地域** | 中高層住宅＋大規模店舗（1,500㎡以下） | ｜ |
| **第1種住居地域** | 住宅＋店舗（3,000㎡以下）、事務所 | ｜ |
| **第2種住居地域** | 住宅＋店舗（10,000㎡以下）、ホテル | ｜ |
| **準住居地域** | 住宅＋自動車修理工場など、住環境を守る必要がある地域 | ｜ |
| **近隣商業地域** | 近隣住民の日用品を供給する店舗・事務所 | ｜ |
| **商業地域** | 百貨店、映画館、遊技場など商業全般 | ｜ |
| **準工業地域** | 軽工業、住宅、店舗 | ↓ |
| **工業地域** | 工場全般、住宅（住環境は重視しない） | 弱い |
| **工業専用地域** | 工場のみ。住宅・店舗は不可 | 最も弱い（制限大） |
| **田園住居地域** | 農業と調和した低層住宅 | 強い |

### 開発許可（都市計画法第29条〜第35条）

**開発行為**とは、**主として建築物の建築の用に供する目的で行う土地の区画形質の変更**をいいます。

> **開発許可が必要な開発行為**
> - **市街化区域**：**1,000㎡以上**の開発行為
> - **市街化調整区域**：**原則としてすべて**の開発行為（例外あり）
> - **非線引き都市計画区域**：**3,000㎡以上**の開発行為
> - **準都市計画区域**：**3,000㎡以上**の開発行為

---

### 都市計画施設

**都市計画施設**とは、都市の骨格となる施設で、都市計画に定められるもの：

| 種類 | 例 |
|:---|:---|
| **交通施設** | 道路、鉄道、駐車場 |
| **公園・緑地** | 都市公園、緑地 |
| **供給施設** | 水道、電気、ガス |
| **処理施設** | 下水道、清掃工場 |
| **教育・文化施設** | 学校、図書館、美術館 |

---

### 地区計画

**地区計画**とは、**地区レベルできめ細かいルール**を定める制度です。

各自治体が地区の特性に応じて、以下の項目を定めます：
- 道路の配置
- 敷地の最小規模
- 壁面の位置
- 建築物の高さ
- 意匠・デザイン

---

### 宅建試験で出るポイントまとめ

1. **13種類の用途地域**（それぞれどんな建物が建てられるか）
2. **開発許可が必要な規模**（市街化区域1,000㎡、調整区域は原則全部）
3. **市街化区域 vs 市街化調整区域**の違い
4. **用途制限の強さの順番**を覚える
5. **都市計画施設と地区計画**の違い

宅建試験「権利関係」の物権編、物権変動に続く**占有権と所有権**の単元。

**「持ってる」**（占有）と **「持ってる権利がある」**（所有）の違いを正しく理解することがこの単元の核心です。

この単元では、**占有権の種類・効力**と、**所有権の取得・共有・境界確定**を学びます。

---

### そもそも「占有権」と「所有権」の違い

| | 占有権 | 所有権 |
|:---|:---|:---|
| **意味** | 物を事実上支配している状態に対する権利 | 物を全面的に支配する権利（使用・収益・処分） |
| **根拠** | 事実状態の保護 | 法律上の権利 |
| **取得方法** | 物を所持すれば自動的に取得 | 売買・相続・取得時効など |
| **保護** | 占有訴訟（本権の有無を問わない） | 本権訴訟（所有権に基づく） |

つまり、**占有権は「今持っている」という事実を保護する権利**であり、**所有権は「持つ権利がある」という法律上の権利**です。

---

### 占有権の種類

占有権は、**占有者の主観的意思**によっていくつかの種類に分類されます。

| 種類 | 内容 | 民法の条文 |
|:---|:---|:---:|
| **自主占有** | 自分の物だと信じて占有する（賃借人・預かり人以外） | 180条 |
| **他主占有** | 他人の物と知りながら占有する（賃借人・預かり人） | 180条 |
| **善意占有** | 権利があると信じて占有する | 189条 |
| **悪意占有** | 権利がないと知りながら占有する | 190条 |
| **平穁占有** | 暴力を使わずに占有する | 判例 |
| **公然占有** | 隠さずに占有する | 判例 |

#### 自主占有と他主占有

**自主占有**＝所有者としての意思を持って占有すること
例：自分の土地だと思って住んでいる人

**他主占有**＝所有者としての意思なしに占有すること
例：賃借人（借主）・受寄者（預かり人）・質権者

> **ポイント（民法第180条）：**
> 占有権は、**自己のためにする意思**をもって物を所持することによって取得する。
> → 自主占有の意思が必要。ただし、占有の開始時に自主占有の意思があれば、その後も自主占有と推定される（民法第186条）。

#### 善意占有と悪意占有

**善意占有**＝権利があると信じている占有
例：売買契約をしたが登記がまだの人

**悪意占有**＝権利がないと知っている占有
例：盗人・無権原の占有者

| | 善意占有 | 悪意占有 |
|:---|:---:|:---:|
| **果実の取得** | 取得する（189条） | 返還義務あり（190条） |
| **取得時効の期間** | 10年（善意無過失） | 20年 |
| **占有訴権** | あり | あり |
| **費用償還請求権** | 必要費＋有益費（選択権あり） | 必要費のみ |

### 占有訴権（占有権の保護）

占有権が侵害された場合、占有者は**占有訴権**を行使できます（民法第197条〜第202条）。

| 種類 | 内容 | 期間 |
|:---|:---|:---:|
| **占有保持の訴え** | 占有を妨害されている者がその妨害の排除を請求 | 妨害がある間＋妨害があった時から1年 |
| **占有保全の訴え** | 占有を妨害されるおそれがある場合にその予防を請求 | 妨害の危険がある間 |
| **占有回収の訴え** | 占有を奪われた場合にその返還を請求 | 奪取された時から1年 |

**占有訴権の特徴（超重要）：**
- 占有訴権は、**本権（所有権）の有無を問わず行使できる**
- つまり、**盗人でも占有者が暴力で追い出されたら占有回収の訴えができる**
- 占有訴権は**本権の訴えと併用できる**（競合）

### 所有権の取得原因

所有権の取得方法には以下の種類があります。

| 取得原因 | 内容 | 民法の条文 |
|:---|:---|:---:|
| **売買** | 契約による所有権の移転 | 555条 |
| **相続** | 被相続人の財産を承継 | 882条 |
| **取得時効** | 長期占有による所有権取得 | 162条 |
| **遺贈** | 遺言による財産の承継 | 964条 |
| **添付** | 付合・混和・加工による所有権取得 | 242条〜248条 |
| **無主物先占** | 所有者のない動産を取得 | 239条 |
| **遺失物拾得** | 落とし物を拾得 | 240条 |
| **埋蔵物発見** | 埋まっている物を発見 | 241条 |

#### 添付（付合・混和・加工）

**付合**：異なる所有者の物が結合して分離不可能になった場合
- 不動産の付合（242条）：不動産の所有者が従たる物の所有権を取得
- 動産の付合（243条）：主たる動産の所有者が従たる物の所有権を取得

**混和**：異なる所有者の物が混ざって区別できなくなった場合（245条）→ 動産の付合の規定を準用

**加工**：他人の物に工作を加えて新たな物を作り出した場合（246条）
- 加工によって生じた価格が材料の価格を超える場合 → **加工者が所有権を取得**
- そうでない場合 → **材料の所有者が所有権を取得**

### 共有（民法第249条〜第264条）

**共有**とは、**一人の物を複数の人が共同で所有している状態**を指します。

#### 共有の基本ルール

| 項目 | 内容 |
|:---|:---|
| **共有者の権利** | 各共有者は持分に応じて物全体を使用できる（249条） |
| **持分の処分** | 各共有者は自由に持分を処分できる（他人に売ってもOK） |
| **共有物の管理** | 各共有者の**過半数**で決する（252条） |
| **共有物の変更** | **全員の同意**が必要（251条） |
| **分割請求** | 各共有者は**いつでも分割を請求できる**（256条） |
| **分割方法** | 現物分割・代金分割・競売 |

#### 共有物の管理（超重要）

| 行為 | 決定方法 | 内容 |
|:---|:---|:---|
| **保存行為** | 各共有者が単独でできる | 壊れた屋根の修理など現状維持 |
| **管理行為** | 持分の過半数で決する | 賃貸契約の更新など |
| **変更行為** | 全員の同意が必要 | 建物の取り壊し・土地の形状変更 |

#### 共有物分割（256条）

各共有者は、**いつでも共有物の分割を請求できる**（不分割の特約がある場合を除く）。

**分割方法：**
1. **現物分割**：物理的に分ける（土地を分割して各自所有）
2. **代金分割**：売却して代金を分ける（競売）
3. **価格賠償**：一人が取得して他の共有者に金銭を支払う

### 境界確定（民法第223条〜第224条）

隣地との境界が不明な場合、**境界確定の訴え**を提起できます。

| 項目 | 内容 |
|:---|:---|
| **境界標の設置** | 隣地所有者は共同で境界標を設置できる（223条） |
| **境界標の保存** | 境界標の設置・保存費用は等しい割合で負担（224条） |
| **境界確定の訴え** | 境界が不明な場合、裁判所に確定を請求できる |

### 宅建試験で出るポイントまとめ

1. **占有権と所有権の違い**（事実と権利）
2. **占有権の種類**（自主占有・他主占有・善意占有・悪意占有）
3. **占有訴権**（本権の有無を問わない）
4. **所有権の取得原因**（特に添付のルール）
5. **共有のルール**（管理・変更・分割の違い）
6. **境界確定**（隣地との境界問題）

### 最後に：占有権・所有権の本質

この単元の本質はたった一言です。

> **「持ってる」は事実。持つ権利があるは法律。**

- **占有権**：今持っている者を保護する（＝自力救済の禁止、平和秩序の維持）
- **所有権**：持つ権利がある者を保護する（＝自由な使用・収益・処分）
- **共有**：複数人で所有する場合のルール
- **境界**：隣接地との権利関係の明確化

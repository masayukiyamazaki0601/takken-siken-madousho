宅建試験「権利関係」の物権編、占有権・所有権に続く**用益物権（ようえきぶっけん）**の単元。

**「他人の土地を使う権利」**には4つの種類があり、それぞれ権利の内容・存続期間・譲渡性が異なります。

この単元では、**地上権・永小作権・地役権・入会権**の4つを横断的に比較しながら整理します。

---

### 用益物権とは

**用益物権**とは、**他人の土地を使用収益する権利**の総称です。

民法は以下の**4種類**の用益物権を定めています。

| 用益物権 | 内容 | 民法の条文 |
|:---|:---|:---:|
| **地上権** | 工作物（建物）や竹木を所有するために他人の土地を使用する権利 | 265条〜269条 |
| **永小作権** | 耕作・牧畜のために他人の土地を使用する権利 | 270条〜279条 |
| **地役権** | 自分の土地（要役地）の便益のために他人の土地（承役地）を使用する権利 | 280条〜294条 |
| **入会権** | 地域の住民が共同で山林・原野などを使用する権利 | 263条〜294条 |

宅建試験で最も出るのは**地上権**と**地役権**です。

---

### 地上権（民法第265条〜第269条）

**地上権**とは、**工作物（建物）や竹木を所有するために、他人の土地を使用する権利**です。

> **地上権の定義（民法第265条）**
> 地上権者は、他人の土地において工作物又は竹木を所有するため、その土地を使用する権利を有する。

#### 地上権の特徴

| 項目 | 内容 |
|:---|:---|
| **目的** | 工作物（建物）・竹木の所有のため |
| **設定方法** | 契約（当事者の合意） |
| **存続期間** | **特約がない限り30年**（民法第268条） |
| **譲渡性** | **自由に譲渡できる** |
| **賃料（地代）** | 必要なし（無償でも可） |
| **登記** | 必要（第三者対抗要件） |
| **借地権との関係** | 借地権（借地借家法）は地上権をベースにした法定の権利 |

#### 地上権と借地権の違い（超重要）

宅建試験で頻出なのが**地上権と借地権の違い**です。

| 項目 | 地上権（民法） | 借地権（借地借家法） |
|:---|:---|:---|
| **根拠法** | 民法 | 借地借家法 |
| **存続期間** | 30年（特約なければ） | 30年（最低） |
| **更新** | 自由（契約による） | 法定更新あり（正当事由が必要） |
| **譲渡** | 自由 | 地主の承諾が必要（承諾がないと契約解除される） |
| **存続性** | 契約自由 | 借主保護が強い（正当事由がないと明渡し不可） |

---

### 永小作権（民法第270条〜第279条）

**永小作権**とは、**耕作または牧畜のために他人の土地を使用する権利**です。

> **永小作権の定義（民法第270条）**
> 永小作人は、耕作又は牧畜を目的として、他人の土地を使用する権利を有する。

#### 永小作権の特徴

| 項目 | 内容 |
|:---|:---|
| **目的** | 耕作・牧畜のため |
| **設定方法** | 契約 |
| **存続期間** | **20年以上50年以下**（民法第278条） |
| **更新** | 期間満了後も、**20年〜50年の範囲内**で更新可能 |
| **譲渡性** | **制限あり**（地主の承諾が必要な場合がある） |
| **小作料** | 必要（金銭または生産物） |
| **登記** | 必要（第三者対抗要件） |

**地上権との違い：**
- 地上権は**建物所有目的**、永小作権は**耕作・牧畜目的**
- 地上権は**無償でも可**、永小作権は**小作料が必要**
- 地上権は**自由に譲渡可能**、永小作権は**譲渡に制限あり**

---

### 地役権（民法第280条〜第294条）

**地役権**とは、**自分の土地（要役地）の便益のために、他人の土地（承役地）を使用する権利**です。

> **地役権の定義（民法第280条）**
> 地役権者は、設定行為で定めた目的に従い、他人の土地（承役地）を自己の土地（要役地）の便益に供する権利を有する。

**【具体例】**
- Aさんの土地（要役地）から公道に出るために、Bさんの土地（承役地）を通る通路として使用する権利（通行地役権）
- Aさんの土地に水道管を通すために、Bさんの土地の地下を使用する権利

#### 地役権の特徴

| 項目 | 内容 |
|:---|:---|
| **目的** | 要役地の便益のため |
| **設定方法** | 契約（要役地と承役地の所有者間の合意） |
| **存続期間** | **特に制限なし**（永久でも可） |
| **譲渡性** | **要役地とともに譲渡される**（地役権単独では譲渡不可） |
| **承役地の所有者** | 地役権の妨害をしてはならない（受忍義務） |
| **登記** | 必要（第三者対抗要件） |

#### 地役権の種類

| 種類 | 内容 |
|:---|:---|
| **通行地役権** | 他人の土地を通って出入りする権利 |
| **水道地役権** | 他人の土地に水道管を設置する権利 |
| **眺望地役権** | 他人の土地に高い建物を建てさせない権利 |
| **日照地役権** | 他人の土地に日影をつくらせない権利 |

#### 地役権の消滅

地役権は以下の場合に消滅します（民法第282条）：
1. 承役地の所有者が要役地の所有権を取得した場合（混同）
2. 要役地または承役地が滅失した場合
3. 時効（20年間行使しない場合）
4. 地役権の放棄（承役地の所有者の承諾が必要）

### 入会権（民法第263条〜第294条）

**入会権**とは、**地域の住民（入会集団）が共同で山林・原野・漁場などを使用する権利**です。

> **入会権の定義（民法第263条）**
> 入会権者は、入会集団に属する者として、共同の利益のために山林・原野等を使用する権利を有する。

#### 入会権の特徴

| 項目 | 内容 |
|:---|:---|
| **目的** | 地域住民の共同利益（薪炭・肥料・漁業など） |
| **主体** | 入会集団（地域住民の共同体） |
| **客体** | 山林・原野・漁場など |
| **権利の性質** | **共有（総有）** |
| **存続期間** | 特に制限なし（慣習による） |
| **登記** | 不要（慣習による権利） |

### 4つの用益物権の横断比較

| 項目 | 地上権 | 永小作権 | 地役権 | 入会権 |
|:---|:---:|:---:|:---:|:---:|
| **目的** | 建物・竹木の所有 | 耕作・牧畜 | 要役地の便益 | 共同利用 |
| **存続期間** | 30年（特約なければ） | 20年〜50年 | 制限なし | 制限なし（慣習） |
| **譲渡性** | 自由 | 制限あり | 土地とともに | 原則不可 |
| **有償性** | 無償でも可 | 有償（小作料） | 無償でも可 | 無償 |
| **登記** | 必要 | 必要 | 必要 | 不要 |
| **試験頻出度** | ⭐⭐⭐⭐⭐ | ⭐⭐⭐ | ⭐⭐⭐⭐⭐ | ⭐⭐ |

### 宅建試験で出るポイントまとめ

1. **地上権**：建物所有目的。30年。譲渡自由。借地権との違いが超重要
2. **永小作権**：耕作・牧畜目的。20年〜50年。譲渡制限あり
3. **地役権**：要役地の便益目的。存続期間制限なし。要役地とともに譲渡
4. **入会権**：地域住民の共同利用。登記不要。慣習による

### 最後に：用益物権の本質

この単元の本質はたった一言です。

> **「他人の土地を使う権利にもいろいろある。目的と期間と譲渡性を覚えろ。」**

- **地上権**：建物を建てるための権利。30年。自由に譲渡できる
- **永小作権**：畑を耕すための権利。20〜50年。譲渡には制限あり
- **地役権**：自分の土地のための権利。半永久的。土地と一緒に移る
- **入会権**：村全体で使う権利。登記不要。慣習が全て
